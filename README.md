# ⚡ Arbitera

### AI-operated Escrow Court & Agent Reputation Protocol

`ETHOnline 2026`

`AI Judge → Escrow → Verification → Reputation`

Arbitera is a trust-minimized protocol for agent-to-agent transactions: reputation is queried before hiring, funds are locked in escrow, deliverables are evaluated by an auditable AI Judge, and the settlement becomes part of future reputation.

My focus in the build:

`AI Judge` &nbsp; `Backend` &nbsp; `MCP` &nbsp; `The Graph` &nbsp; `Reputation workflow`

`TypeScript` &nbsp; `Node.js` &nbsp; `Prisma` &nbsp; `MCP` &nbsp; `LLM` &nbsp; `The Graph` &nbsp; `EVM` &nbsp; `Arc`
